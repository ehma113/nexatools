A QUICK GUIDE

Solve percentage questions without the guesswork

Calculate a percentage of a number, find what percentage one value is of another, or compare an old value with a new one. Choose the calculation mode that matches the question.

How to use it

  1. Choose the calculation type.
  2. Enter the values in the fields.
  3. Select Calculate and read the result.
Helpful tip

For discounts, calculate the percentage of the original price first. For percentage change, compare the difference with the starting value.

GOOD TO KNOW

Frequently asked questions

Quick explanations of percentage-of, percentage-change and reverse percentage calculations.

How do I calculate a discount?
Use the percentage-of mode to find the discount amount, then subtract that amount from the original price.
What does percentage change mean?
It compares a new value with an original value and expresses the difference as a percentage of the original value.
Why can't I use zero as the original value?
Percentage change divides by the original value. A zero starting value would make that division undefined.
