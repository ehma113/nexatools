A QUICK GUIDE

Understand file sizes across storage units

Convert a file size between bytes, kilobytes, megabytes, gigabytes and terabytes. This calculator uses binary multiples of 1,024 for each step.

How to use it

  1. Enter a numeric file size.
  2. Choose the unit you are starting from.
  3. Review the equivalent values in the result.
Helpful tip

File-size units can be decimal (1,000) or binary (1,024). This calculator uses 1,024-based units, which is common for operating-system file-size displays.

GOOD TO KNOW

Frequently asked questions

Answers about bytes, kilobytes, megabytes and binary file-size calculations.

Does this use 1,000 or 1,024?
This calculator uses 1,024-based binary steps, which are commonly used by operating systems when displaying some file sizes.
Why does a website show a different file size?
Some services use decimal units based on 1,000, while others use binary units based on 1,024.
Does it inspect a file on my computer?
No. Enter the size manually. It does not read files or access your storage.
