A QUICK GUIDE

Tidy text copied from different sources

Clean up extra spaces and blank lines that can appear when copying text from websites, PDFs or messages. Choose the cleanup options that suit the text you want to keep.

How to use it

  1. Paste the text to clean.
  2. Choose which spacing and blank-line rules to apply.
  3. Select Clean text and copy the result.
Helpful tip

Preview the cleaned text before replacing your original. Some spacing and line breaks may carry meaning in code, tables or poetry.

GOOD TO KNOW

Frequently asked questions

Learn which text changes can be made and why you should review the output.

Will it remove paragraph breaks?
Only if you select the option to remove blank lines. Ordinary line breaks can be retained.
Does it change spelling or punctuation?
No. The cleaner focuses on whitespace and line formatting, not proofreading.
Can I undo the cleanup?
The original input remains available in the input area until you replace it. Copy the result only when it looks right.
