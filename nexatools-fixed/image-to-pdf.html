A QUICK GUIDE

Turn images into a shareable PDF

Combine image files into a PDF document. This is useful for scanned pages, receipts, notes and photos you need to share as one file.

How to use it

  1. Select one or more supported image files.
  2. Choose Create PDF.
  3. Save the generated PDF to your device.
Helpful tip

Use clear, upright images and check the order before creating the PDF. Very large photos can produce a larger document.

GOOD TO KNOW

Frequently asked questions

Learn about image formats, page order and how images are placed into the PDF.

Which image formats can be used?
The tool supports common browser-readable images, including JPEG and PNG, and may convert other browser-readable formats before adding them.
Will each image get its own page?
Yes. Each selected image is placed on its own PDF page.
Can I rearrange the image order?
The images are processed in the order returned by the file picker. Rename or select files in the desired order before converting.
