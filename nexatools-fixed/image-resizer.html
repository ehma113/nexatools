Use the image resizer

Processing happens locally in your browser. Very large images may use significant device memory.

A QUICK GUIDE

Resize images to the dimensions you need

Set a target width and height to prepare an image for a website, document or upload form. Keep the aspect ratio enabled when you want to avoid stretching the image.

How to use it

  1. Choose an image file.
  2. Enter the target width and height in pixels.
  3. Keep the ratio option on to preserve proportions, then process and download.
Helpful tip

If the image must not look stretched, keep the aspect-ratio option enabled. Start from the original file to avoid repeated quality loss.

GOOD TO KNOW

Frequently asked questions

Learn about pixel dimensions, aspect ratios and image quality after resizing.

What is aspect ratio?
Aspect ratio describes the proportional relationship between an image's width and height, such as 16:9 or 1:1.
Why does the image look stretched?
The ratio option may be turned off while using dimensions with a different proportion from the original.
Does resizing improve image quality?
Resizing changes pixel dimensions. Enlarging a small image cannot restore detail that was not present in the original.
