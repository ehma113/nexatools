A QUICK GUIDE

Generate random numbers within a range

Set a minimum and maximum value and choose how many numbers to generate. Use the results for classroom activities, games, sampling or other low-stakes random selections.

How to use it

  1. Enter the minimum and maximum values.
  2. Choose how many numbers you need.
  3. Generate the results and copy them if required.
Helpful tip

Set the lower and upper limits before generating. The selected range includes both endpoints, so check that it matches your intended use.

GOOD TO KNOW

Frequently asked questions

Answers about number ranges, repeat results and how random values are selected.

Can the same number appear more than once?
Yes, unless you select the unique-results option. Repeated values are possible in ordinary random sampling.
Are the results suitable for lotteries or security?
No. This is a general-purpose browser utility, not a certified lottery, gambling or security randomisation system.
Can I generate decimal values?
This version generates whole numbers within the inclusive range you provide.
