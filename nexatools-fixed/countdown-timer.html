A QUICK GUIDE

Set a countdown for a task or break

Choose minutes and seconds, then start a countdown. Keep the page open while the timer runs; when it reaches zero, the page displays a completion message.

How to use it

  1. Set the minutes and seconds.
  2. Press Start to begin the countdown.
  3. Pause, resume or reset the timer when needed.
Helpful tip

Set a realistic duration and keep the page open while the countdown runs. Browser or device power-saving settings may affect background timers.

GOOD TO KNOW

Frequently asked questions

Answers about countdown accuracy, background tabs and changing the timer duration.

Can I enter seconds only?
Yes. Set minutes to zero and enter the seconds value.
Will it alert me if the tab is closed?
No. Keep the page open. Closing the tab stops the page timer.
Can I pause and continue later?
Yes. Use Pause, then Start to continue from the remaining time.
