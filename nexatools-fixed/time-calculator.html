Use the tool

A QUICK GUIDE

Add or subtract hours and minutes

Combine two time durations or find the difference between them. Use it for shifts, schedules, study sessions and time tracking.

How to use it

  1. Enter the first duration in hours and minutes.
  2. Choose Add or Subtract.
  3. Enter the second duration and calculate.
Helpful tip

When adding time, enter minutes from 0 to 59. For work shifts that cross midnight, check whether your result should include the next day.

GOOD TO KNOW

Frequently asked questions

Answers about adding time, subtracting time and working with minute values.

Can the result exceed 24 hours?
Yes. The result is a duration, not a clock time, so totals can be longer than one day.
Can I subtract a longer duration from a shorter one?
Yes. The result is shown as a negative duration when the second value is larger.
Does it calculate time zones?
No. This tool adds and subtracts durations; it does not convert between time zones.
