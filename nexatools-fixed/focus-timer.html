A QUICK GUIDE

Give one task your full attention

Set a focused work interval, start the timer and take a break when the session ends. A simple timer can help structure study, reading, practice or a short work sprint.

How to use it

  1. Choose a session length.
  2. Press Start when you are ready.
  3. Pause if needed, or Reset to begin again.
Helpful tip

Choose a session length that suits the task. A short break between focused sessions can make it easier to return with attention.

GOOD TO KNOW

Frequently asked questions

Answers about focus sessions, breaks and keeping the timer running reliably.

Can I change the session length?
Yes. Choose a different duration before starting or reset the timer after changing it.
Does the timer keep running if I close the tab?
No. Keep the page open while using the timer. Closing or refreshing the page may end the current session.
Is this a Pomodoro timer?
It can be used for a Pomodoro-style session. You choose the duration; the page does not enforce a particular work-and-break routine.
