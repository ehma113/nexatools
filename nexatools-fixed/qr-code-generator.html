A QUICK GUIDE

Make a QR code from a link or message

Create a QR code that can be scanned by a phone camera. Use it for a website, event information, contact details or a short message. Always scan-test the downloaded image before printing or sharing it.

How to use it

  1. Enter the full website address or text.
  2. Choose Generate QR code.
  3. Scan the preview with your phone, then download the PNG.
Helpful tip

Test the downloaded QR code with a phone camera before printing. Keep a clear margin around it and make sure the destination link is still active.

GOOD TO KNOW

Frequently asked questions

Find out how QR codes work, how long they last and how to test one before sharing.

Will the QR code expire?
A QR code generated from plain text or a URL does not have an expiry date. The destination can still change if the website or link is removed.
Can I use it on a flyer?
Yes. Download the PNG and test it at the size you plan to print. Leave a clear margin around the code.
Why won't my phone scan it?
Check that the code is not cropped or blurry, increase its printed size, and make sure there is strong contrast between the code and its background.
