A QUICK GUIDE

Create a random password for an account

Choose a password length and the character groups to include. The generator uses your browser's cryptographic random-number generator when available. Store the result in a reputable password manager rather than reusing it across accounts.

How to use it

  1. Choose the password length.
  2. Select the character groups you want to include.
  3. Generate the password, then copy it into your password manager.
Helpful tip

Use a different long password for every account and save it in a trusted password manager. Never send a password to anyone or reuse it across important accounts.

GOOD TO KNOW

Frequently asked questions

Understand how random passwords are created and how to store them safely.

Is the password generated on a server?
No. The password is generated locally in your browser and is not sent to NexaTools.
Should I reuse one generated password?
No. Use a different password for each account. Reusing passwords can put multiple accounts at risk if one service is compromised.
Why must I select at least one character type?
The generator needs a defined set of characters to choose from. Select at least one group before generating.
