A QUICK GUIDE

Turn spreadsheet-style CSV into JSON

Paste comma-separated values with a header row to create an array of JSON objects. Each header becomes a property name and each following row becomes an object.

How to use it

  1. Paste CSV with column names on the first row.
  2. Choose Convert to JSON.
  3. Review the output and download or copy it.
Helpful tip

Make sure the first row contains the column names if you want object-style JSON. Check quoted commas and line breaks in the source CSV.

GOOD TO KNOW

Frequently asked questions

Answers about column headings, quoted values and converting rows into JSON records.

Does the first row become field names?
Yes. The first row is treated as the header row and its values become JSON property names.
Can fields contain commas?
Yes, if the CSV uses standard double-quote wrapping around fields that contain commas.
What happens if a row has fewer columns?
Missing cells are converted to empty strings so each output object follows the same header structure.
