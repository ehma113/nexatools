A QUICK GUIDE

Resize dimensions without stretching

Enter a source width and height, then provide one new dimension. The calculator works out the other dimension while preserving the original proportions.

How to use it

  1. Enter the original width and height.
  2. Enter either the new width or the new height.
  3. Calculate the matching dimension.
Helpful tip

Enter the original dimensions first, then change one target dimension. The other value is calculated to preserve the same proportions.

GOOD TO KNOW

Frequently asked questions

Answers about proportional resizing, common ratios and rounding pixel dimensions.

What is a 16:9 ratio used for?
16:9 is common for widescreen video and presentation formats. Other uses may require 1:1, 4:3 or custom proportions.
Will the result always be a whole number?
Pixel dimensions are rounded to the nearest whole pixel, so a tiny rounding difference can occur.
Can I change both dimensions independently?
This calculator preserves the original ratio. If you need different proportions, use the image resizer and disable its ratio lock.
