A QUICK GUIDE

Inspect image dimensions and file details

Choose an image to view its pixel dimensions, format, file size and aspect ratio. The file is read locally by your browser; this page does not upload it.

How to use it

  1. Choose an image from your device.
  2. Wait for the image details to appear.
  3. Review the dimensions, format, size and ratio.
Helpful tip

Metadata can include camera or device details and sometimes location information. Review it before sharing images publicly.

GOOD TO KNOW

Frequently asked questions

Understand which image details may be available and how metadata affects privacy.

Does it show camera EXIF information?
This version shows basic file and image properties such as dimensions, MIME type and size. It does not extract detailed camera EXIF metadata.
Is my image uploaded?
No. The browser reads the selected image locally to display its basic properties.
Why are dimensions useful?
They help you check whether an image is large enough for a website, document, thumbnail or social post.
