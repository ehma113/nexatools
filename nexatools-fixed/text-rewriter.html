A QUICK GUIDE

Make wording clearer and easier to read

Use simple rewrite presets to make selected phrases more concise, clear or formal. The tool applies a limited set of wording substitutions, so always read the result and adjust it to your meaning.

How to use it

  1. Paste the text you want to revise.
  2. Choose a rewrite style.
  3. Run the tool and review the suggested wording.
Helpful tip

Use the rewrite as an editing starting point. Check names, technical terms and the original meaning before you publish or submit the revised text.

GOOD TO KNOW

Frequently asked questions

Learn how to use a rewrite responsibly and keep the meaning of your original text.

Is this an AI paraphraser?
No. It uses a small set of phrase substitutions in your browser. It does not understand the full context like a language model.
Can it change the meaning?
A substitution may not fit every context. Review the output carefully and keep the original if a phrase changes your intended meaning.
Can I use it for academic writing?
You can use it to review wording, but follow your institution's rules and make sure the final work reflects your own understanding.
