A QUICK GUIDE

Make JSON easier to read and validate

Paste JSON to check whether its syntax is valid. Format it with indentation for easier reading, or minify it to remove unnecessary whitespace. This tool does not repair incorrect JSON automatically.

How to use it

  1. Paste JSON into the editor.
  2. Choose Format to indent it or Minify to compact it.
  3. If validation fails, read the error and correct the indicated syntax.
Helpful tip

If validation fails, inspect the exact line and column in the error message. JSON requires double quotes around strings and property names.

GOOD TO KNOW

Frequently asked questions

Understand JSON validation, formatting and the limits of working with very large data.

What makes JSON invalid?
Common causes include missing commas, trailing commas, unquoted property names, single quotes and unmatched braces or brackets.
Does formatting change the data?
Formatting changes whitespace and indentation only. It preserves the JSON values and structure when the input is valid.
Can I use this for large JSON files?
It works best for text that your browser can comfortably handle. Very large files may use substantial memory.
