PDF Merger

Combine multiple PDF files into one document.

Free to useRuns in your browserNo account needed

Merge PDF files

Files are processed in your browser. Password-protected PDFs may not work.

A QUICK GUIDE

Bring separate PDFs into one organised file

Combine several PDF documents into a single file in the order you select them. This is useful for joining forms, class notes, reports and supporting documents before sharing.

How to use it

  1. Select at least two PDF files.
  2. Arrange the files in the order you want them merged.
  3. Choose Merge PDFs and save the combined document.
Helpful tip

Rename files or arrange them in the intended order before merging. Open the final PDF and check the page sequence before sharing it.

GOOD TO KNOW

Frequently asked questions

Answers about file order, PDF compatibility and checking your merged document.

Can I merge more than two PDFs?
Yes. Select multiple files at once. They are added to the merged document in the order provided by the file picker.
Will the original PDFs be changed?
No. The tool creates a new merged file and leaves the original files on your device unchanged.
Why might a PDF fail to merge?
A password-protected, damaged or unusually structured PDF may not be supported. Try opening the source file in a PDF reader first.
