Use the tool

A QUICK GUIDE

Crop an image to keep only what matters

Use the cropper to create a smaller image area around the subject you want to keep. The current crop is centred, based on the width and height you enter.

How to use it

  1. Choose an image.
  2. Enter the output width and height.
  3. Process the crop and download the new image.
Helpful tip

Keep the original image untouched until you have checked the crop. Leave a little extra space around important subjects if the image will be reused.

GOOD TO KNOW

Frequently asked questions

Answers about crop dimensions, image quality and keeping the original file.

Can I move the crop area with my mouse?
This version creates a centred crop from the dimensions you enter; it does not provide a draggable crop frame.
What happens if the crop is larger than the source?
The tool limits the crop dimensions to the source image so it does not create an empty area.
Does cropping overwrite my original?
No. The cropper creates a separate output image.
