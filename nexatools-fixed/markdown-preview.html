GOOD TO KNOW

Frequently asked questions

Understand which Markdown elements are previewed and how to copy the rendered result.

Which Markdown features are supported?
This preview supports common headings, paragraphs, lists, bold, italic, inline code and links. It is not a full CommonMark implementation.
Can I paste HTML?
The preview treats input as Markdown text and escapes raw HTML for safety.
Does it publish my Markdown?
No. It is a local preview tool and does not publish or save a page online.
